# VapeCalc

Native macOS e-liquid mixing calculator (SwiftUI, no third-party dependencies). Enter the PG/VG ratio,
batch volume, nicotine base and flavours; get every component in ml, grams and percent, and keep your
recipes in a local library.

## Features

- Per-component volume, weight and percentage; weight uses carrier density at 20 °C
  (PG 1.036 g/ml, VG 1.261 g/ml), computed in `Decimal` so `15 × 1.261` rounds correctly.
- Any number of flavours, each on a PG or VG carrier; a mix that no longer fits the ratio is flagged.
- Recipe library with autosave, search, duplicate, delete with undo and "Variant…" (same proportions
  at a different volume or nicotine strength).
- Flavour suggestions with typical dosages from a bundled catalogue.
- English and Russian UI.

## Requirements and build

macOS 14+, Swift 6 (Xcode 16 or later).

```sh
./build.sh                # universal (arm64 + x86_64), ad-hoc signed build/VapeCalc.app
open build/VapeCalc.app
swift test
```

`build.sh` copies the SwiftPM resource bundle, the `Resources/*.lproj` folders, the icon and
`Info.plist` into the app. The icon is drawn in code: `Tools/make_icns.sh` renders
`Tools/make_icon.swift` into `Resources/AppIcon.icns`.

## Languages

English is the development language: strings live in code, Russian translations in
`Resources/ru.lproj` (`Localizable.strings`, `Localizable.stringsdict` for plurals, `InfoPlist.strings`).
The app follows the system language; to force one:

```sh
open -n build/VapeCalc.app --args -AppleLanguages '(ru)'
```

## Inputs

| Field | Range | Step |
|---|---|---|
| PG / VG ratio | 0–100 % PG | 5 |
| Target volume | 0–5000 ml | 5 |
| Nicotine base strength | 0–1000 mg/ml, PG or VG carrier | presets 100/150/200/500 |
| Nicotine in liquid | 0–100 mg/ml | 0.5 |
| Flavour | 0–30 % each, PG or VG carrier | 1 |

## Formulas

Results match the [elsmoke.com.ua](https://elsmoke.com.ua/calc-diy.html) online calculator.
`Sources/VapeCalcCore/Recipe.swift` is an independent Swift implementation of the same formulas and
rounding: volumes are rounded with JavaScript `toFixed` semantics (the exact binary value of the double,
ties away from zero), since naive rounding drifts by 0.01 ml on some inputs.

`swift test` checks it against 410 fixtures generated by running that calculator's JavaScript
(`Tests/VapeCalcCoreTests/Fixtures/reference_cases.json`: 10 hand-picked cases + 400 fuzzed).

## Recipe library

Selecting a recipe loads it into the calculator; edits are saved automatically. With nothing selected
the calculator is a draft until "Save as Recipe" (⌘S). ⌘N new draft, ⌘D duplicate, ⌘⌫ delete,
⌘Z undo delete.

Storage is one JSON file, `~/Library/Application Support/com.vapecalc.desktop/library.json`, written
atomically with a schema version. A file that fails to decode is moved aside as
`library.corrupt-<timestamp>.json`; a file from a newer schema version is refused rather than overwritten.

## Flavour suggestions

Typing two characters into a flavour name offers matches from the bundled catalogue
(`Sources/VapeCalcCore/Resources/flavors.json`, 7440 flavours across 75 brands, each with a typical
dosage): arrows move, Enter picks, Escape closes. For a known flavour the row shows `≈2.2%` — click to
apply it, hover for the usage range and the number of recipes behind it. If the catalogue is missing the
app runs with suggestions turned off.
